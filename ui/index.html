Ctrl + Enter — отправить

Настройки проекта

Папка нужна только для анализа проекта и изменения файлов.

Можно вставить «Копировать как путь» из Проводника — кавычки допустимы.

Для анализа и изменений Gemini получает только безопасную копию. Секреты, .git/.gemini, symlink и типичные build/dependency папки исключаются.
